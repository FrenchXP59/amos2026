01 · Le principe

Le vibe coding, c'est quoi ?

Tu décris ce que tu veux en français, une IA écrit le code, tu regardes le résultat et tu corriges en lui parlant. Tu ne codes pas : tu diriges. C'est le même métier que celui d'un chef de projet face à une agence.

1

Tu décris

Un prompt clair : pour qui, quoi, quel style, quelles sections. Plus ton brief est précis, moins tu corriges.

2

L'IA construit

Un agent crée les fichiers dans ton dossier : une page HTML, une feuille de style, un peu de JavaScript.

3

Tu juges

Tu ouvres la page, tu demandes une correction à la fois. Ton œil et ta relecture font la qualité, pas l'outil.

L'IA écrit vite. C'est toi qui signes. Chaque texte, chiffre ou image publiés engagent ton nom, ton asso ou ton client.

02 · Le critère n°1

Ton site peut-il partir avec toi ?

Avoir « accès au code » ne suffit pas. La vraie question : si demain l'outil change ses prix ou ferme ton compte, ton site continue-t-il de tourner ailleurs ?

Le bon réflexe

Démarre gratuitement avec Antigravity, poursuis si besoin avec Claude Code ou Codex : ce sont les mêmes fichiers, dans le même dossier. Tu changes d'outil, pas de site.

Sources consultées le 4 novembre 2026 : doc Lovable (GitHub) · export Base44 · offres Antigravity (source tierce). Les offres gratuites changent souvent : vérifie au moment de t'inscrire.

03 · Le parcours

Du dossier vide au site en ligne.

Six étapes, sans terminal ni compte développeur. Compte une heure pour une première landing page.

1
La base

Crée ton dossier

Tout part d'un dossier sur ton ordinateur. Tu y ranges tes images et tes infos ; l'IA ira les chercher. C'est ce dossier qui fait de toi le propriétaire de ton site.

📁 mon-site/
 ├─ brief.md # qui, quoi, pour qui, ton, couleurs
 ├─ images/ # logo.png, photo-1.jpg…
 └─ textes/ # tes vrais textes
Images de moins de 500 Ko, noms simples sans espace ni accent (equipe-1.jpg).
2
Hors quota

Prépare ton prompt

Avec le générateur ci-dessous, ou dans un chat gratuit (ChatGPT, Claude, Gemini). Préparer le prompt hors de l'outil, c'est garder ton quota pour la construction.

  • 15 à 20 lignes : au-delà, le site devient surchargé.
  • Demande à l'IA de lire brief.md et le dossier images/.
  • Exige des emplacements [à compléter] plutôt que des chiffres inventés.
3
Gratuit à date

Lance l'IA dans ton dossier

Ouvre le dossier dans Antigravity (Google), colle ton prompt, laisse l'agent créer index.html. Ouvre ce fichier dans ton navigateur : ton site est là.

// L'agent écrit dans TON dossier :
index.html  ✦ créé
style.css   ✦ créé
script.js   ✦ créé
4
Une chose à la fois

Corrige et sauvegarde

Une demande par message : « agrandis le titre », « remplace la photo ». Les corrections se font dans l'outil, qui voit tes fichiers.

Avant chaque gros changement, copie ton dossier : mon-site-v1, mon-site-v2… Si l'IA casse tout, tu reviens en arrière en 10 secondes.
5
30 secondes

Mets-le en ligne

Crée ton compte gratuit Netlify, puis glisse ton dossier sur la page Netlify Drop. Ton site a une adresse publique en .netlify.app.

  • Le dossier glissé doit contenir index.html.
  • Mise à jour : onglet Deploys du même site, pas un nouveau dépôt.
6
Pour aller plus loin

Ton nom, ta marque

Un nom de domaine à toi (Namecheap, par exemple), relié à Netlify. Puis, quand tu es à l'aise : GitHub, Claude Code ou Codex.

  • tonprojet.com au lieu de tonprojet.netlify.app
  • GitHub : l'historique automatique de tes versions

      07 · Les pièges
      
Huit erreurs à ne pas faire.

    

    

      
Une clé dans le code
Jamais de clé d'API ni de mot de passe dans tes fichiers : un site est lisible par tous (clic droit, « Afficher le code source »).

      
Le site qui disparaît
Déposé sans compte Netlify, ton site expire. Crée ton compte avant de glisser ton dossier.

      
Pas de copie
L'IA peut tout casser en une demande. Une copie du dossier avant chaque gros changement, toujours.

      
Le formulaire sans RGPD
Collecter des e-mails, c'est traiter des données personnelles : mention d'information obligatoire, données minimales.

      
L'image « trouvée sur Google »
Elle a un auteur. Utilise tes photos, des banques libres de droits, et l'accord des personnes photographiées.

      
L'icône invisible
Une icône Lucide qui ne s'affiche pas ? Son nom n'existe sûrement pas : vérifie-le sur lucide.dev, ou colle son code avec le bouton « Copy SVG ».

      
Le domaine qui expire
Un nom de domaine se loue à l'année. Active le renouvellement automatique, sinon ton adresse peut être rachetée par un autre.

      
Les faux avis
L'IA invente volontiers chiffres, logos partenaires et témoignages. Publier de faux avis est une pratique commerciale trompeuse.

Relié à Netlify, chaque modification envoyée met ton site à jour tout seul. Attention : un dépôt public est visible par tout le monde.

Ce que j'utilise au quotidien : des agents plus puissants, qui travaillent dans ton dossier sur des projets plus ambitieux (plusieurs pages, base de données, applis).
Ils nécessitent un abonnement payant. Bonne nouvelle : ils reprennent exactement les fichiers créés avec Antigravity.
